# Figure Provenance

The PNG files in `figures/manuscript/` were supplied by the authors for the PComA-CORE manuscript and are included as fixed visual artefacts. They are not regenerated from patient-level data within this public archive.

Exact regeneration requires the locked source tables, OOF predictions, temporal predictions, calibration objects, decision-curve inputs, learning-curve estimates, bootstrap results, and era-specific denominators. Generated diagnostic figures created by the reference scripts are written to `figures/generated/` and must not replace the fixed manuscript figures unless numerical concordance has been formally verified.
